# Uncertainty-Aware Decision Making in Multimodal Large Language Models

Research materials for **Uncertainty-Aware Decision Making in Multimodal Large Language Models: A Survey of Sources, Signals, Calibration, and Actions**.

**Authors:** Abderrahmene Boudiaf, Irfan Hussain and Sajid Javed.

[Read the manuscript on arXiv](https://arxiv.org/abs/2608.17084v1).

## Repository status

This repository is being prepared. The supporting study-level evidence is undergoing verification and correction. A complete independently verified evidence release is not yet available here.

The historical evidence matrix contains 67 focused study records. A later working version adds one explicitly non-counted bridge record. Historical corpus counts should be distinguished from any corrected release counts.

## Literature search

[SEARCH_STRATEGY.md](SEARCH_STRATEGY.md) records the representative query templates, documented sources and the author's approximate search period. These are descriptions of the search strategy rather than a complete database-by-database execution log.

## Planned evidence release

The evidence matrix, field dictionary and correction history will be added as clearly versioned materials. Each release should distinguish the historical inventory from corrected records, state verification limitations, and identify relevant source versions.
